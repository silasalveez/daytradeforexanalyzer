# 📈 FX Pro - DayTrade Analyzer

Uma aplicação web avançada para análise técnica em tempo real de ativos de Forex e Criptomoedas, focada em entregar recomendações de Day Trade com alta assertividade e gestão de risco otimizada (Risco/Retorno de 1:3 a 1:5).

## 🚀 Funcionalidades Principais

*   **Radar de Oportunidades:** Escaneamento automático a cada 20 segundos buscando setups de alta probabilidade nos ativos abertos na sessão.
*   **Análise Multi-Timeframe (MTF):** Algoritmo que cruza dados do contexto Macro (Diário/4H) com refinamento de entrada no Micro (15m/5m).
*   **Filtro Institucional (Smart Money Concepts):** Alertas baseados em Order Blocks, Fair Value Gaps (FVG) e captura de liquidez.
*   **Gestão de Risco Blindada:** As operações recomendadas são estritamente calculadas para preservar capital, com indicações claras de Entrada, Stop Loss e Take Profit.
*   **Catalisadores Macroeconômicos:** Integração de impacto de notícias globais na ação do preço.
*   **Relógio Global de Sessões:** Acompanhamento em tempo real (Horário de Brasília - BRT) da abertura e fechamento de mercados (Tóquio, Londres, Nova York, Sydney e mercado Cripto 24/7).

## 🛠️ Tecnologias Utilizadas

*   **Frontend:** React, Tailwind CSS
*   **Ícones:** Lucide React
*   **Gráficos:** TradingView Advanced Chart Widget
*   **Dados em Tempo Real:** Integração com APIs de câmbio (Fiat) e Binance API (Criptomoedas).

## 📱 Responsividade

A interface foi projetada (Mobile-First e Desktop) para oferecer a experiência de um aplicativo financeiro nativo direto do navegador, sem necessidade de instalação pesada.

## ⚠️ Aviso Legal

Esta ferramenta tem fins educacionais e de análise técnica. O mercado de renda variável envolve altos riscos. Sempre utilize o Stop Loss recomendado e gerencie o tamanho do seu lote (Position Sizing) adequadamente.
